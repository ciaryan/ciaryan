## About me

Hi, I'm Ciarán (KEER-awn) — an AI Engineer and Data Scientist at the **Government Digital Service**, where I work on [Gov UK Chat](https://gds.blog.gov.uk/2026/05/14/gov-uk-chat-launches/) ([github](https://github.com/alphagov/govuk-chat)). I integrate LLMs, build RAG evaluation pipelines, and improve the quality, safety, and routing of AI systems for public services. While you're here, I'm a Google Certified ML Engineer and AWS Certified AI Practitioner.

- 💻 Work GitHub: [ciaran-ryan-gds](https://github.com/ciaran-ryan-gds)

Previously I was a Data Scientist & Strategist at **Publicis Sapient**, leading work across audience segmentation, graph ML recommendation engines, and multi-agent prototyping for executive decision-making.

I hold a First Class Honours MA in Statistics and a BSc in Medicinal Chemistry from University College Dublin. I wrote a [blog post in 2020 about how I made that transition](https://statitouille.wordpress.com/2020/08/29/graduate-life-in-2020-why-you-should-say-no-to-phds-and-go-back-to-school/). 

## Work Experience

### Government Digital Service — AI Engineer and Data Scientist

- **Routing and safety:** Engineered a Ruby on Rails routing agent across 13 intent pathways, including self-knowledge questions and mental health crisis detection, while avoiding unnecessary retrieval to reduce latency and token costs.
- **RAG retrieval:** Improved OpenSearch context selection and structured retrieved content with document hierarchy, page titles, and metadata to improve relevance while controlling prompt size.
- **Automated evaluation:** Re-architected benchmark preparation for [`govuk-chat-evaluation`](https://github.com/alphagov/govuk-chat-evaluation), enabling batch measurement of faithfulness, context relevancy, and answer relevancy.
- **LLM-as-a-judge:** Calibrated an AWS Bedrock/Claude judge to penalise ambiguous or ungrounded claims instead of accepting them as faithful.
- **Human evaluation:** Designed and led an evaluation with 35 GDS content designers, measuring 86% answer accuracy and identifying hallucination and data-availability issues.
- **Observability:** Designed production metrics for clarification loops and "false hope" patterns across user conversations.

### Publicis Sapient — Data Scientist and Strategist

- **Multi-agent decision support:** Designed and prototyped an expert focus group for executive decisions, combining distinct agent roles with Bloomberg, Financial Times, and live market data.
- **Graph ML recommendations:** Built a Neo4j and Cypher substitution engine for a retailer, helping retain £50M in revenue through real-time out-of-stock recommendations.
- **Time-series forecasting:** Built a Python and SQL EWMA demand-forecasting engine that delivered a 30% uplift in add-to-cart conversions.
